<objective>
Add per-appearance pitch trend analysis that computes velocity and movement for each pitch type across the most recent appearance, the lookback window average, and the prior-season baseline. This enables the trends specialist to distinguish three patterns: one-off regression (last_start != window_avg, last_start ~ prior_season), sustained change (last_start ~ window_avg, both != prior_season), and something-new (last_start != both).

Purpose: Give the trends specialist the three-way comparison it needs to classify pitch characteristic changes as noise vs real trend vs new development.
Output: AppearancePitchTrends dataclass, compute function, PitcherContext integration, trend specialist wiring.
</objective>

    **pattern_label logic:**
    Use the velo delta to classify. Compare the raw numeric deltas (not the strings):
    - `last_vs_window_delta = last_start_velo - window_avg_velo`
    - `last_vs_prior_delta = last_start_velo - prior_season_velo` (if available)
    - "steady": both abs(deltas) < _VELO_THRESHOLD
    - "one-off": abs(last_vs_window) >= _VELO_THRESHOLD AND (prior is None OR abs(last_vs_prior) < _VELO_THRESHOLD)
    - "sustained change": abs(last_vs_window) < _VELO_THRESHOLD AND prior is not None AND abs(last_vs_prior) >= _VELO_THRESHOLD
    - "something new": abs(last_vs_window) >= _VELO_THRESHOLD AND prior is not None AND abs(last_vs_prior) >= _VELO_THRESHOLD
    When prior_season_velo is None, can only be "steady" or "one-off".

    **compute_appearance_pitch_trends(data: PitcherData) -> AppearancePitchTrends | None:**
    1. Get window game dates via `_get_window_game_dates(data)`. Return None if empty.
    2. Find the most recent game_date in the window (max).
    3. Filter `data.statcast` to current season only (game_date year == max(game_date).year) -- this gives season-level statcast.
    4. Filter statcast to window game dates -- this gives window statcast.
    5. Filter statcast to last_game_date only -- this gives last-start statcast.
    6. Group each (last-start, window, season-wide) by pitch_type, compute mean release_speed, mean pfx_x * 12 (convert feet to inches), mean pfx_z * 12.
    7. For prior season: filter data.statcast to game_date year < max_game_date.year, group by pitch_type, compute same metrics. If empty, prior = None per pitch type.
    8. For each pitch_type in last-start with >= _MIN_PITCHES: build AppearancePitchTrendRecord with delta strings and pattern_label.
    9. Sort records by n_pitches_last descending.
    10. Return AppearancePitchTrends with last_game_date and records.

    Add `AppearancePitchTrendRecord`, `AppearancePitchTrends`, `compute_appearance_pitch_trends` to `__all__`.
