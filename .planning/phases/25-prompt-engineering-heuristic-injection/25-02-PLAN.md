<objective>
Add a causal hook requirement to the writer prompt and a sabermetric heuristic whitelist to the auditor prompt, so the writer must cite physical drivers for large S+ changes and the auditor does not false-positive on evidence-backed analytical patterns.

Purpose: Without the causal hook, the writer can mention a 15-point S+ drop without explaining why. Without the whitelist, the auditor flags valid inverse-correlation analysis (velo down + S+ up because movement compensated) as hallucination. These two changes work in tandem: the writer cites the mechanism, the auditor validates the citation.

Output: Modified `_build_writer_prompt()` with CAUSAL HOOK REQUIREMENT section, modified `_DATA_AUDITOR_PROMPT` with ALLOWED HEURISTIC PATTERNS section, and test coverage for both.
</objective>

```

CAUSAL HOOK REQUIREMENT:
When ANY pitch shows a Stuff+ change of 10 or more points (window vs \
season S+ delta), you MUST cite the physical driver from the Stuff \
Specialist's analysis. Connect the S+ change to the velocity, \
movement, or spin change that explains it.

```

ALLOWED HEURISTIC PATTERNS:
The following analytical patterns are VALID when the specialist cites \

Key rule: the pattern is valid ONLY when evidence is cited. Pattern \
recognition alone, without citing the specific metrics, is still a \
category 5 violation.
