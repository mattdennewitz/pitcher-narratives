    **Step 1: Add three dataclasses to engine.py** (insert after the existing FirstPitchEntry dataclass, before the Public API section):

    ```python
    @dataclass
    class CountBucketUsage:
        """Per-pitch-type usage rate within a single count-state bucket."""
        pitch_type: str
        pitch_name: str
        usage_pct: float
        """Usage as percentage of all pitches in this bucket (0-100)."""

    @dataclass
    class CountBucket:
        """Usage breakdown for a single count state."""
        bucket: str
        """One of: 'ahead', 'behind', 'even', 'two_strike', 'first_pitch'."""
        n_pitches_window: int
        n_pitches_season: int
        small_sample: bool
        """True when n_pitches_window < _MIN_PITCHES (10)."""
        pitch_types: list[CountBucketUsage]
        """Window-period per-pitch-type usage rates, sorted by usage descending."""
        season_pitch_types: list[CountBucketUsage]
        """Season-level usage rates for delta computation."""

    @dataclass
    class CountSplits:
        """Per-pitch-type usage across count states with window vs season deltas."""
        buckets: list[CountBucket]
        """Five buckets: ahead, behind, even, two_strike, first_pitch."""
        notable_shifts: list[str]
        """Pre-rendered strings for shifts >= 10pp, for inline rendering. Empty for small-sample buckets."""
    ```

    **Step 2: Add bucket filter expressions** as a module-level dict (near the constants section):

    ```python
    _COUNT_BUCKETS: dict[str, pl.Expr] = {
        "ahead": pl.col("strikes") > pl.col("balls"),
        "behind": pl.col("balls") > pl.col("strikes"),
        "even": pl.col("balls") == pl.col("strikes"),
        "two_strike": pl.col("strikes") == 2,
        "first_pitch": (pl.col("balls") == 0) & (pl.col("strikes") == 0),
    }
    ```

    Per D-01: Two-strike overlaps with ahead/behind/even. A pitch at 1-2 is in both "ahead" and "two_strike".
    Per D-02: First-pitch (0-0) is also in "even" bucket.

    **Step 3: Implement `compute_count_splits(data: PitcherData) -> CountSplits`:**

    Logic:
    1. Call `_get_window_game_dates(data)` to get window dates and `_is_cold_start(data)` for cold start detection.
    2. Call `_build_name_map(data)` for pitch type code -> human name mapping.
    3. For each bucket in `_COUNT_BUCKETS`:
       a. Filter `data.statcast` by the bucket expression to get season-level pitches.
       b. Further filter by window dates to get window-level pitches.
       c. Compute per-pitch-type usage_pct within the bucket (count of each type / total bucket pitches * 100).
       d. Build `CountBucketUsage` lists for both window and season.
       e. Set `small_sample = (n_pitches_window < _MIN_PITCHES)` per D-03/D-04.
    4. Compute notable_shifts: For each non-small-sample bucket, for each pitch type, if abs(window_pct - season_pct) >= 10.0 pp (per D-11), add a formatted string like: `"{pitch_name} usage {direction} {delta:.0f}pp when {bucket_label} ({window_pct:.0f}% vs {season_pct:.0f}% season)"`. Use human-readable bucket labels: ahead="Ahead in count", behind="Behind in count", even="Even count", two_strike="Two-strike counts", first_pitch="First pitch".
    5. Return `CountSplits(buckets=buckets, notable_shifts=notable_shifts)`.

    **Step 4: Update `__all__`** in engine.py to include `"CountBucketUsage"`, `"CountBucket"`, `"CountSplits"`, `"compute_count_splits"`.

    **Step 5: Write tests** in tests/test_engine.py. Use the existing pattern of building synthetic Polars DataFrames. Create a fixture with known ball/strike counts and pitch types so bucket membership and usage percentages are deterministic. Test cases per the behavior block above.
