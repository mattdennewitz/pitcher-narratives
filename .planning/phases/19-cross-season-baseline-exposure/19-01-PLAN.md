# Phase 19 Plan 01: Cross-Season Baseline Exposure

## Objective

Extend PitcherData to expose prior-season baselines alongside current-season baselines, enabling downstream phases (20-22) to compute year-over-year deltas. Currently load_pitcher_data() filters baselines to the max season only -- this plan removes that filter and adds prior_season_baseline and prior_pitch_type_baseline fields.

## Context

@src/pitcher_narratives/data.py -- PitcherData dataclass and load_pitcher_data()
@tests/test_data.py -- Existing data tests

## Tasks

### Task 1: Add prior-season fields to PitcherData
type="auto"

Add `prior_season_baseline: pl.DataFrame` and `prior_pitch_type_baseline: pl.DataFrame` fields to the PitcherData dataclass. These hold the season before the max season's baselines.

**Done when:** PitcherData has 2 new DataFrame fields.

### Task 2: Modify load_pitcher_data to split baselines
type="auto"

Change load_pitcher_data() so that:
- season_baseline and pitch_type_baseline contain ONLY the max (current) season rows (preserving existing behavior for all downstream consumers)
- prior_season_baseline contains the season before max season rows
- prior_pitch_type_baseline contains the season before max season pitch-type rows
- When only one season exists, prior_* fields are empty DataFrames (same schema, zero rows)

**Done when:** load_pitcher_data returns PitcherData with all 4 baseline fields correctly populated.

### Task 3: Add tests for multi-season baseline exposure
type="auto"

Write tests covering:
- XSBL-01: Multi-season pitcher gets both current and prior baselines populated
- XSBL-02: load_pitcher_data retains all season data (current in season_baseline, prior in prior_season_baseline)
- XSBL-03: Single-season pitcher gets empty (not None, not crash) prior baselines
- Regression: existing engine functions still work (pitch_type_baseline still has current season only)

**Done when:** All new and existing tests pass.

### Task 4: Update __all__ exports
type="auto"

Ensure any new public functions or constants added to data.py are in __all__. Verify PitcherData fields are documented in docstrings.

**Done when:** __all__ is up to date, PitcherData docstring reflects new fields.
