**Step 2: Create `src/pitcher_narratives/resolver.py`.**

The module must contain:

1. **Module docstring** (Google-style): "Fuzzy pitcher name resolution from Statcast parquet data."

2. **Imports** (grouped per convention):
   - stdlib: `from __future__ import annotations`, `import unicodedata`, `from dataclasses import dataclass`
   - third-party: `import polars as pl`, `from nameparser import HumanName`, `from rapidfuzz import fuzz, process`
   - local: `from pitcher_narratives.data import PARQUET_PATH`

3. **`__all__`**: `["ResolveResult", "resolve"]`

4. **Constants**:
   - `_SCORE_CUTOFF = 70`
   - `_MAX_CANDIDATES = 5`

5. **`ResolveResult` dataclass** (per locked decision):
   ```python
   @dataclass
   class ResolveResult:
       pitcher_id: int | None
       pitcher_name: str | None
       candidates: list[tuple[int, str]]
       match_type: str  # "exact" | "exact_last" | "fuzzy" | "ambiguous" | "not_found"
   ```

6. **`_NameTable` dataclass** (private, for caching):
   ```python
   @dataclass
   class _NameTable:
       full_index: dict[str, tuple[int, str]]       # "dylan cease" -> (656302, "Cease, Dylan")
       last_index: dict[str, list[tuple[int, str]]]  # "cease" -> [(656302, "Cease, Dylan")]
   ```

7. **Module-level cache**: `_name_table: _NameTable | None = None`

8. **`_strip_diacritics(s: str) -> str`**: Apply `unicodedata.normalize("NFKD", s)` and filter out combining characters.

9. **`_normalize(raw: str) -> str`**: Parse with `HumanName(raw)`. If `parsed.last` is non-empty, reconstruct as `f"{parsed.first} {parsed.last}".strip()`. If `parsed.last` is empty (single word), use `parsed.first`. Then apply `_strip_diacritics()`, lowercase, and strip whitespace. Return the result.

10. **`_build_name_table() -> _NameTable`**:
    - Check `global _name_table`; return cached if not None.
    - Read parquet: `pl.read_parquet(PARQUET_PATH, columns=["pitcher", "player_name"])`.
    - Get unique pitchers: `.unique(subset=["pitcher"])`.
    - Iterate rows with `iter_rows(named=True)`. For each row:
      - Parse `row["player_name"]` (format "Last, First") with `HumanName`.
      - Build `full_norm = _normalize(f"{parsed.first} {parsed.last}")`.
      - Build `last_norm = _strip_diacritics(parsed.last).lower().strip()`.
      - Add to `full_index[full_norm] = (pid, original)`.
      - Append to `last_index.setdefault(last_norm, [])`.
    - Sort each `last_index` entry by name alphabetically for deterministic ordering.
    - Cache in `_name_table` and return.

11. **`resolve(query: str) -> ResolveResult`**: The public function. Tiered pipeline:
    - Call `_build_name_table()` to get/build the cache.
    - Normalize the query with `_normalize(query)`.
    - **Also** compute `query_last_norm = _strip_diacritics(query).lower().strip()` for single-word matching, and a separate `_normalize` for multi-word.
    - For single-word queries (no space in normalized form): check last_index first for exact match, then full_index.
    - For multi-word queries: check full_index first for exact match, then last_index with the last-name component.

    **Tier 1 -- Exact full-name match**: If `normalized` is in `table.full_index`, return with `match_type="exact"`.

    **Tier 2 -- Exact last-name match**: Determine the last-name component. For single-word input, use the normalized form directly. For multi-word, extract via `HumanName`. If that key is in `table.last_index`:
      - If exactly 1 entry: return with `match_type="exact_last"`.
      - If multiple: return with `match_type="ambiguous"`, `candidates=entries[:_MAX_CANDIDATES]`, sorted by name asc.

    **Tier 3 -- Fuzzy full-name match**: `process.extract(normalized, table.full_index.keys(), scorer=fuzz.WRatio, limit=_MAX_CANDIDATES, score_cutoff=_SCORE_CUTOFF)`. If results:
      - If top result score is significantly above rest (>=5 points gap) or only 1 result: return the top match with `match_type="fuzzy"`.
      - If multiple close results: collect all corresponding (pitcher_id, name) pairs, deduplicate, sort by (score desc, name asc), return as `match_type="ambiguous"` if >1, or `match_type="fuzzy"` if 1.

    **Tier 4 -- Fuzzy last-name match**: `process.extract(normalized_for_last, unique_last_names, scorer=fuzz.WRatio, limit=_MAX_CANDIDATES, score_cutoff=_SCORE_CUTOFF)`. If results:
      - Expand each matched last name to its full entries from `last_index`.
      - Deduplicate by pitcher_id, sort by (score desc, name asc), limit to `_MAX_CANDIDATES`.
      - If 1 unique pitcher: return with `match_type="fuzzy"`.
      - If multiple: return with `match_type="ambiguous"`.

    **Tier 5 -- Not found**: Return `ResolveResult(pitcher_id=None, pitcher_name=None, candidates=[], match_type="not_found")`.

**CRITICAL implementation notes from research pitfalls:**
- Single-word queries: `HumanName("Cease")` puts "Cease" in `.first`, not `.last`. Must check against BOTH full_index AND last_index for single-word inputs.
- Build the index with suffix-stripped names: stored "Leiter Jr., Mark" is indexed as "mark leiter" (no suffix).
- Last-name index keys also strip suffixes: "leiter" not "leiter jr".
- Sort candidates by `(score desc, name asc)` for deterministic output, not score alone.
- Use `_strip_diacritics` on BOTH stored names (during index build) and user input (during query).
