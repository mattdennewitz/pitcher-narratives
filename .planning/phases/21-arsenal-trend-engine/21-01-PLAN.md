# Phase 21 Plan 01: Arsenal Trend Engine

## Objective

Compute year-over-year per-pitch-type deltas (added/dropped pitches, usage shifts, P+/S+/L+ changes, velocity changes) so that reports can surface arsenal evolution across seasons.

## Context

- @src/pitcher_narratives/engine.py - existing computation engine with delta string helpers
- @src/pitcher_narratives/data.py - PitcherData with agg_csvs containing multi-year data
- @tests/test_engine.py - existing engine test patterns

## Tasks

### Task 1: ArsenalTrend dataclasses and compute function
type="auto"

Create `ArsenalTrend` and `PitchTrend` dataclasses and a `compute_arsenal_trends()` function in engine.py.

**Implementation:**

1. Add `ArsenalTrend` dataclass with fields: `added_pitches`, `dropped_pitches`, `pitch_trends`, `prior_season`, `current_season`
2. Add `PitchTrend` dataclass with fields: `pitch_type`, `pitch_name`, `prior_usage_pct`, `current_usage_pct`, `usage_delta`, `prior_p_plus`, `current_p_plus`, `p_plus_delta`, `prior_s_plus`, `current_s_plus`, `s_plus_delta`, `prior_velo`, `current_velo`, `velo_delta`
3. Add `AddedDroppedPitch` dataclass with fields: `pitch_type`, `pitch_name`, `usage_pct`, `n_pitches`, `season`
4. Implement `compute_arsenal_trends(data: PitcherData) -> ArsenalTrend | None`:
   - Extract all seasons from pitch_type baseline data (agg_csvs["pitcher_type"])
   - If fewer than 2 seasons, return None (ATRN-03)
   - Identify current (max) and prior season
   - Compute per-season pitch_type baselines using existing compute_pitch_type_baseline
   - Find pitches in current but not prior = added (ATRN-01)
   - Find pitches in prior but not current = dropped (ATRN-01)
   - For shared pitches, compute YoY deltas using existing delta string helpers (ATRN-02)
   - Use _MIN_PITCHES threshold to filter noise from added/dropped detection

**Done criteria:**
- ArsenalTrend, PitchTrend, AddedDroppedPitch dataclasses exist
- compute_arsenal_trends returns ArsenalTrend for multi-season pitchers
- compute_arsenal_trends returns None for single-season pitchers
- Uses existing delta string helpers for consistency

Write comprehensive tests for the arsenal trend engine.

**Implementation:**

1. Create synthetic test data with multi-season pitcher_type agg data
2. Test added pitch detection (pitch in 2026 not in 2025)
3. Test dropped pitch detection (pitch in 2025 not in 2026)
4. Test YoY delta computation for shared pitches (usage, P+, S+, velocity)
5. Test single-season pitcher returns None (ATRN-03)
6. Test minimum pitch threshold filters out noise
7. Test with real test pitcher data if multi-season data exists

**Done criteria:**
- All tests pass

## Success Criteria

1. Engine identifies pitches present in prior season but absent in current (dropped) and vice versa (added) -- ATRN-01
2. Engine computes per-pitch-type YoY deltas for usage rate, P+, S+, and velocity -- ATRN-02
3. When pitcher has only one season of data, arsenal trend output is None -- ATRN-03
