### 1. `SCOUT` missing from `personas.__all__` (minor)

### 2. `cli.py` does not forward `persona` to `check_hallucinated_metrics` (latent)

**Severity:** latent — the safety net built in Phase 07/08 is inactive in production. No user-visible symptom today because analyst/generic vocabulary terms don't match `_METRIC_PATTERN` anyway, but the design intent (per PERSONA-10) was for the allowlist to be active whenever a persona is selected.

**Current:**
```python
hallucination_report = check_hallucinated_metrics(pipe_result.narrative)
```

**Should be:**
```python
hallucination_report = check_hallucinated_metrics(pipe_result.narrative, persona=args.persona)
```

**Why the phase verifications missed this:** Phase 07/08 tests invoked `check_hallucinated_metrics(text, persona="analyst")` directly. Phase 09 tests checked argparse parsing of `--persona`. Neither test traced the CLI's actual call to the hallucination guard.
