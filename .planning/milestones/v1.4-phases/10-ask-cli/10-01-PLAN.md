    4. `_extract_pitcher_name(question: str) -> tuple[str | None, ResolveResult | None]`:
       - Import `from pitcher_narratives.resolver import resolve, ResolveResult` inside function (lazy)
       - Tokenize question into words
       - Strip trailing `'s` and `'` from each word (handle possessives like "Cease's")
       - Generate candidate phrases: all contiguous 3-word, then 2-word, then 1-word subsequences
       - For each candidate, call `resolve(candidate)`
       - First result with `match_type in ("exact", "exact_last", "fuzzy")` -> return `(candidate, result)`
       - Track the best ambiguous result encountered for fallback
       - If all candidates exhausted with no definite match but an ambiguous result exists, return `(None, ambiguous_result)`
       - If nothing matches, return `(None, None)`

    5. `parse_args() -> argparse.Namespace`:
       - `description="Ask a question about a pitcher's recent performance"`
       - Positional: `"question"`, `nargs="?"`, help text
       - `-w` / `--window`: `type=int`, `default=30`
       - `--provider`: `choices=["openai", "claude", "gemini"]`, `default="claude"` (per CONTEXT.md locked decision)
       - `--thinking`: `choices=["minimal", "low", "medium", "high", "xhigh"]`, `default="high"`

    6. `main() -> None`:
       - `load_dotenv()`
       - `args = parse_args()`
       - If `not args.question`: print usage hint to stderr, `sys.exit(1)`
       - Call `_extract_pitcher_name(args.question)` -> `(query, result)`
       - If `result` is None (not found): `print(f"No pitcher found matching '{args.question}'", file=sys.stderr)`, `sys.exit(1)`
       - If `result.match_type == "ambiguous"`: print "Multiple pitchers matched. Use a more specific name." to stderr, then numbered candidates list `"  {i}. {name} (ID: {pid})"`, `sys.exit(1)`
       - Extract `pitcher_id = result.pitcher_id`
       - Test model override (same pattern as cli.py lines 136-140): check `PITCHER_NARRATIVES_TEST_MODEL` env var BEFORE API key check
       - API key pre-flight: `_API_KEYS = {"openai": "OPENAI_API_KEY", "claude": "ANTHROPIC_API_KEY", "gemini": "GEMINI_API_KEY"}`, if no override and key missing -> print error, exit 1
       - Lazy imports: `from pitcher_narratives.data import load_pitcher_data`, `from pitcher_narratives.context import assemble_pitcher_context`, `from pitcher_narratives.analyst import ask_question_streaming`
       - `try: pitcher_data = load_pitcher_data(pitcher_id, args.window)` with `except ValueError as e: print(str(e), file=sys.stderr); sys.exit(1)`
       - `ctx = assemble_pitcher_context(pitcher_data)`
