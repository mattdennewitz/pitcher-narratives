## Overview

Reports surface year-over-year changes — a pitcher who added a sweeper, gained 2 mph, or saw Stuff+ collapse gets that story told automatically. Cross-season baselines, delta engines, and prompt rendering wired end-to-end.

## Milestone Summary

**Key Accomplishments:**
1. PitcherData exposes prior-season baselines via prior_season_baseline and prior_pitch_type_baseline fields
2. CrossSeasonSummary dataclass with YoY deltas for velocity, P+/S+/L+, and workload
3. Arsenal trend engine with added/dropped pitch detection and per-pitch-type delta computation
4. Year-over-Year Changes section renders in LLM prompt; 3 specialist agents receive cross-season context

**Key Decisions:**
- Additive extension pattern for PitcherData (existing fields unchanged, new prior_* fields added)
- Reuse existing qualitative delta string functions for cross-season deltas (consistency)
- Basic workload YoY comparison included (innings, appearances, avg pitches)
- _MIN_PITCHES = 10 threshold reused for arsenal added/dropped detection
- 3 specialists receive YoY data (stuff, trends, game_shape); location and run_value excluded

- None — clean execution across all 4 phases
