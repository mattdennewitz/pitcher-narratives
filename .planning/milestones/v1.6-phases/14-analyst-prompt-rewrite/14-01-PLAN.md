Content must teach 4 sequential steps:

2. **Diagnose location impact** via P-variant (stuff + location) vs S-variant (stuff only). The delta reveals what command adds or subtracts. Include one concrete example like: "xWhiff drops from 38% (P) to 25% (S) -- his location adds 13 percentage points of whiff rate."
3. **Identify the dominant run-value driver** from the component attribution table. Each pitch's xRV100 decomposes into 13 outcome contributions. Instruct: find the 2-3 outcomes contributing the most (positive or negative). Include one example like: "Whiffs contribute -1.4 runs per 100 (saving runs), but home runs give back +0.6 (costing runs)."
4. **Summarize with plus scores** -- after explaining internals, reference P+ (combined), S+ (stuff), L+ (location) as summary grades. P+ above 100 helps the pitcher, below 100 hurts.

Add a `SIGN CONVENTIONS:` sub-section teaching:
- Probability metrics (xSwing, xWhiff, xSwSt): P > S means location increases the rate. Higher xWhiff is good for pitcher, higher xSwing means more balls in play.
- Run value (xRV100): More negative = better for pitcher. P < S means location improves run value.
- Attribution contributions: Negative = pitcher benefits. Positive = costs runs.

**REWRITE: DIAGNOSTIC APPROACH (replace lines 110-123)**

New content must teach a 3-step reasoning chain:
1. **What does the pitch do?** Read intermediate probabilities. High xWhiff = generates misses. High xSwing = hitters can't lay off. Low xRV100 = saves runs.
2. **How much does location help?** Compare P vs S variants. Large positive xWhiff delta = command puts pitch where hitters swing and miss. Small/negative delta = whiffs from stuff alone.
3. **Where do the runs come from?** Read the attribution table. If whiffs dominate negative side = swing-and-miss pitch. If ground outs dominate = weak-contact pitch. If home runs dominate positive side = gopher ball problem.

End with: execution metrics (CSW%, Zone%, Chase%) as supporting evidence, not primary frame. Reference plus scores as summary grades after explaining underlying model signals.
