# Phase 21 Plan 01: Arsenal Trend Engine

## Objective

Build an arsenal trend engine that computes year-over-year per-pitch-type deltas -- identifying pitches added, dropped, or significantly changed between seasons. Produces dataclasses ready for LLM context assembly in Phase 22.

## Context

- @src/pitcher_narratives/engine.py -- existing computation engine with delta string helpers and arsenal summary
- @src/pitcher_narratives/data.py -- PitcherData with multi-year agg_csvs already loaded
- @src/pitcher_narratives/config.py -- shared constants

## Tasks

### Task 1: Arsenal trend dataclasses and computation function
type="auto"

**Action:** Add arsenal trend dataclasses and `compute_arsenal_trends()` to engine.py.

**Dataclasses:**
- `ArsenalPitchTrend`: per-pitch-type YoY delta (usage_pct delta, P+/S+/L+ deltas, velocity delta, all as qualitative strings + raw values). Includes `status` field: "added", "dropped", or "continued".
- `ArsenalTrends`: container with `added: list[ArsenalPitchTrend]`, `dropped: list[ArsenalPitchTrend]`, `continued: list[ArsenalPitchTrend]`, and a `has_data: bool` flag.

**Function:** `compute_arsenal_trends(data: PitcherData) -> ArsenalTrends | None`
- Returns None when pitcher has only one season of data (ATRN-03)
- Computes per-season pitch-type baselines from `agg_csvs["pitcher_type"]` via `compute_pitch_type_baseline()`
- Identifies max season (current) and max-1 season (prior)
- Pitches in current but not prior = "added" (ATRN-01)
- Pitches in prior but not current = "dropped" (ATRN-01)
- Pitches in both = "continued" with YoY deltas for usage_pct, P+, S+, L+, velocity (ATRN-02)
- Uses minimum pitch threshold (_MIN_PITCHES) for inclusion
- Reuses existing `_pplus_delta_string`, `_velo_delta_string`, `_usage_delta_string` helpers

**Done:**
- Function returns None for single-season pitchers
- Added/dropped pitches correctly identified
- Continued pitches have YoY delta strings
- All delta strings use same qualitative language as within-season deltas
